PhonePe Transaction Analysis Dashboard

Project Overview

This project is an interactive PhonePe Transaction Analysis Dashboard developed using Microsoft Power BI. It provides insights into transaction performance, user activity, monthly trends, service types, and customer age segments.

Key Performance Indicators (KPIs)

* Total Transaction Value
* Total Transactions
* Success Rate
* Total Users
* Successful Transactions

Dashboard Features & Analysis

1. Transaction Analysis

* Total Transaction Value
* Total Transactions
* Successful Transactions
* Transaction Success Rate

2. Monthly Trend Analysis

* Monthly Transaction Trend
* Month-over-Month (MoM) Transaction Growth
* Month-over-Month Transaction Value Growth
* Transaction MoM Indicator with Arrows

3. User Analysis

* Total Users
* Users by Age Segment
* Top 5 Users

4. Service Type Analysis

* Transaction Value by Service Type

5. Time-Based Analysis

* Weekday vs Weekend Transactions
* All Months Filter for interactive analysis

6. Interactive Tooltip

* Total Transaction Value by Age Segment displayed through a tooltip.
